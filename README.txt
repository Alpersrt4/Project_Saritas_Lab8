LABORATORY WORK 8 - READY PROJECT
=================================

1) Open Lab8Mvvm.sln in Visual Studio 2022 or newer.
2) If Visual Studio asks, install the ".NET desktop development" workload.
3) Set Lab8Mvvm as Startup Project.
4) Press F5 to run.
5) Open Test > Test Explorer > Run All to execute the 5 xUnit tests.
6) Press Save in the app to create Lab8_MVVM_Data.json in Documents.

Implemented requirements:
- MVVM separation
- INotifyPropertyChanged
- ObservableCollection<T>
- XAML Data Binding / DataContext
- ICommand commands (Add/Delete/Save)
- LINQ filtering
- File saving to JSON
- 5 xUnit tests
- Previous Pwd algorithm retained
